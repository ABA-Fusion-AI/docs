# Barcode/QR Generator

> **Category:** DevOps & Cloud Management | **Type:** Action Node

Generate barcode and QR code images from text input using the **bwip-js** library. The generated image is returned as a Base64-encoded PNG string, making it easy to store, transmit, or embed into applications and workflows.

<!-- /SECTION: header -->

---

<!-- SECTION: overview -->
## Overview

The **Barcode/QR Generator** node creates one-dimensional and two-dimensional barcode images from text input. It supports multiple barcode standards and returns the generated image as a Base64-encoded PNG string.

The node uses the **bwip-js** library internally and allows workflows to generate product barcodes, inventory labels, QR codes, shipping labels, and printable identifiers without relying on external services.

### Key Features

- **Multiple Barcode Formats:** Generate both 1D and 2D barcode types.
- **QR Code Support:** Create QR codes from any text or URL.
- **Base64 PNG Output:** Returns an image encoded as Base64.
- **Custom Appearance:** Configure colors, size, padding, and displayed text.
- **No External API:** Generates images locally without third-party services.
- **Workflow Ready:** Easily integrates into automation pipelines.

### Supported Barcode Types

### Use Cases

- Generate product barcodes
- Create QR codes for websites
- Build inventory labels
- Generate warehouse identifiers
- Produce shipping labels
- Create printable tickets
- Encode serial numbers
- Generate barcode images for documents

## Configuration

### Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `data` | `string` | ✅ Yes | — | Text to encode in the barcode or QR code. |
| `type` | `string` | ❌ No | `code128` | Barcode format to generate. |
| `scale` | `number` | ❌ No | `2` | Image scaling factor. |
| `height` | `number` | ❌ No | `10` | Height of one-dimensional barcodes. |
| `includetext` | `boolean` | ❌ No | `true` | Display the encoded text below the barcode. |
| `textxalign` | `string` | ❌ No | `center` | Alignment of displayed text. |
| `textsize` | `number` | ❌ No | `10` | Font size of displayed text. |
| `padding` | `number` | ❌ No | `10` | Padding around the generated image. |
| `backgroundcolor` | `string` | ❌ No | `FFFFFF` | Background color in hexadecimal (without `#`). |
| `barcolor` | `string` | ❌ No | `000000` | Barcode color in hexadecimal (without `#`). |

### Default Values

| Parameter | Default |
|-----------|---------|
| `type` | `code128` |
| `scale` | `2` |
| `height` | `10` |
| `includetext` | `true` |
| `textxalign` | `center` |
| `textsize` | `10` |
| `padding` | `10` |
| `backgroundcolor` | `FFFFFF` |
| `barcolor` | `000000` |

### Supported Barcode Formats

The node supports the following formats:

- Code 128
- Code 39
- EAN-13
- EAN-8
- UPC-A
- UPC-E
- ITF-14
- MSI
- Pharmacode
- Codabar
- QR Code
- Data Matrix
- PDF417

### Configuration Notes

- Colors must be provided as hexadecimal values without the `#` prefix.
- The `data` parameter is mandatory.
- Higher `scale` values generate larger images.
- The generated output is always a PNG image encoded as Base64.

## Inputs & Outputs

### Inputs

| Input | Type | Description |
|-------|------|-------------|
| `config` | `object` | Barcode generation settings configured directly in the node. |

The node requires the following configuration:

```text
Data: Hello Fusion AI
Type: code128
```

The `data` parameter is mandatory and contains the text to encode.

### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `string` | Base64 PNG | Base64-encoded PNG image generated by the node. |

### Successful Response

The node returns a Base64-encoded PNG image.

Example:

```text
iVBORw0KGgoAAAANSUhEUgAA...
```

The returned value can be:

- Embedded into HTML using a Data URI.
- Decoded into a PNG image.
- Stored in databases.
- Sent to external APIs.
- Saved as an image file.

### Error Response

When barcode generation fails, the node throws an error similar to:

```text
Failed to generate barcode: <error message>
```

## Troubleshooting

### Common Issues

#### "Data is required"

**Cause:** The required `data` parameter is empty.

**Solution:** Provide a non-empty string to encode.

---

#### "Barcode data is required"

**Cause:** No barcode data was provided to the node.

**Solution:** Configure the `data` parameter with the text that should be encoded.

---

#### "Failed to generate barcode"

**Cause:** Barcode generation failed.

Possible reasons include:

- Invalid barcode type.
- Unsupported input data.
- Invalid color values.
- Internal rendering error.

**Solution:**

Verify:

- The selected barcode type.
- The value provided in `data`.
- The color values (`backgroundcolor` and `barcolor`).
- Numeric parameters such as `scale`, `height`, `padding`, and `textsize`.

---

#### Barcode cannot be scanned

**Cause:** The generated barcode is too small or contains invalid data.

**Solution:**

- Increase the `scale` value.
- Increase the `height` for one-dimensional barcodes.
- Verify that the encoded data matches the selected barcode format.

---

#### QR Code is difficult to read

**Cause:** The generated QR Code is too small.

**Solution:**

Increase the `scale` parameter before generating the image.

---

### Error Messages

| Error | Description |
|-------|-------------|
| `Data is required` | The required `data` parameter is missing. |
| `Barcode data is required` | No text was provided for encoding. |
| `Failed to generate barcode` | Barcode generation failed. |
